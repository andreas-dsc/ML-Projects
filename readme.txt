What is this dataset?
The Real Estate Transfer Values ​​Registry (in Greek "Μητρώο Αξιών Μεταβιβάσεων Ακινήτων") is an official digital database maintained by the General Secretariat for Information Systems and the Independent Authority for Public Revenue, which records the actual prices at which real estate transactions take place in Greece. It can be found here: https://www.gov.gr/el/services/1001525/metroo-axion-metabibaseon-akineton

What is it used for?
Valuation: It helps buyers and sellers see the actual prices at which similar properties in a specific area are sold, allowing them to look past the often inflated prices seen in listings. 
Professional use: It serves as a tool for real estate appraisers, brokers, economists, and real estate market data analysts. 
Transparency: It reduces the discrepancy between declared values ​​and actual transaction prices.

Is it a good dataset?
Well not that good, because it does not take account of important property features like the micro-location, the view, the renovation and interior condition or the energy class and heating of the building.
Also for tax reasons the sold value is declared the same as the objective value.
So is it any good?
The biggest advantage of the set is that it records the ground truth of real transactions: Unlike portals like Spitogatos or XE.gr—which only capture asking prices (often inflated by 15%–30% and subject to negotiation)—this dataset records legally executed contracts and real money transfers.
Also, with over 170000 cleaned transactions it provides sufficient statistical power to observe real appreciation.
